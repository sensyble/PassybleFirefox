## Description

Passyble remplit vos mots de passe, codes 2FA, clés d’accès, cartes et adresses, directement dans Firefox.

Gardez votre coffre là où cela vous convient :

* Avec l’application Passyble sur votre ordinateur. L’application contient le coffre, se déverrouille avec Windows Hello et synchronise.
* Dans Firefox lui-même. Aucune application requise : le coffre est chiffré avec votre mot de passe principal et reste dans ce navigateur.

Ce que vous obtenez :

* Identifiants remplis depuis un menu dans le champ, ou avec Ctrl+Shift+L
* Mots de passe robustes créés pour les nouveaux comptes, et enregistrés pour vous
* Codes 2FA remplis à la connexion
* Cartes et adresses remplies dans les formulaires de paiement
* Un verrouillage après le délai de votre choix, et à la fermeture de Firefox

Par défaut, Passyble se contente de consulter account.passyble.com toutes les quelques heures pour connaître la version minimale prise en charge, sans rien envoyer sur vous ni sur votre coffre. La connexion à un compte Passyble ou l’activation de la synchronisation demande d’abord votre accord.

Gratuit. Open source.
