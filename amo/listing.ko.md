## 설명

Passyble은 비밀번호, 2FA 코드, 패스키, 카드, 주소를 Firefox에서 바로 자동으로 입력해요.

보관함은 편한 곳에 두세요.

* 컴퓨터의 Passyble 앱과 함께. 앱이 보관함을 관리하고, Windows Hello로 잠금을 해제하며, 동기화해요.
* Firefox 안에서. 앱이 필요 없어요. 보관함은 마스터 비밀번호로 암호화되어 이 브라우저에 남아요.

이런 기능이 있어요.

* 입력란의 메뉴나 Ctrl+Shift+L로 로그인 정보 입력
* 새 계정용 강력한 비밀번호를 만들어 대신 저장
* 로그인할 때 2FA 코드 입력
* 결제 양식에 카드와 주소 입력
* 정한 시간이 지나면, 그리고 Firefox를 닫으면 잠금

Passyble은 기본적으로 몇 시간마다 account.passyble.com에서 지원되는 최소 버전만 확인하고, 사용자나 보관함에 관한 정보는 아무것도 보내지 않아요. Passyble 계정에 로그인하거나 동기화를 켤 때는 먼저 물어봐요.

무료. 오픈 소스.
